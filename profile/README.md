## Quiénes somos

**HAKUYOMI & Asociados** es una firma tecnológica peruana, con base en Trujillo y Lima, que resuelve problemas reales de cualquier rubro. Para cada proyecto armamos un equipo a medida: profesionales de sistemas junto a un especialista del sector, para que la solución hable el idioma de tu negocio.

1. **Escuchamos** tu idea o tu problema.
